# 千星运行时配置导入

对话、任务、边走边说、场景提供「导入配置」，接受对应「导出千星…」或千星编辑器导出的运行时 JSON，不接受网页编辑器工程 JSON。文件上限 20 MB。

- 对话、边走边说：新建文件，文件名取自导入文件，自动处理非法路径字符；同名自动添加 ` (1)` 等后缀，不覆盖旧文件。
- 任务、场景：解析校验通过后询问是否覆盖；先刷新当前保存队列，再将原始文件备份至 `/<工作区>/ImportBackups/Quest/<UUID>.json` 或 `/<工作区>/ImportBackups/Scene/<UUID>.json`，最后写入固定配置。取消、校验错误、原配置保存失败或备份失败不替换当前配置。备份是编辑器工程格式，不应通过运行时导入按钮导入；可通过工作区存储文件管理恢复原固定路径。
- 所有路径在编辑器打开时固定，异步回调检查卸载状态。写入成功后才更新内存中的编辑项目；导入期间禁止继续编辑或切换。

`runtimeImport.ts` 在调用编辑器转换前，按注册结构体字段位置严格校验原始节点，拒绝缺失/额外字段、错误类型、重复字典键、超限列表和无效数值。结构体 ID 从文件的 structId/value_structId 推断，检查同一类型 ID 一致性，保存为该配置的导出 ID；未出现的空表内部类型沿用默认 ID。字典键必须匹配自身 ID，子任务/二级区域保留完整 ID 和原分桶，不自动重新编号。

对话还原支持 Dialogue、Select、Camera、条件分支、Focus Push、Custom 和 PublicEvent。按 Timer 分配开始时间，按 NextGroup 的出口槽建立连线（-1 保持未连接），包含回环。运行时不含画布位置、节点名称、Clip/预设编辑身份，导入后重新排列；公共事件按类型重建匿名参数，保留类型内顺序和值，无法恢复原名称、条件显示规则和预设来源。

当前编辑器无法无损表达的数据会拒绝导入并指出位置：例如未知 actionType、单 Group 多个 Dialogue/Select、延时或混合条件分支、自连、未引用的数据表条目、Select 的非空额外 params、与 Timeline 末尾规则冲突的台词时长。不会跳过未知动作后仍报告成功。

回归：`node scripts/test-dsfg-runtime-import.cjs`。测试包含四类运行时往返、自定义 ID、空配置、回环/未连接出口、损坏配置、同名新增、覆盖备份、取消及保存失败、卸载后禁止写入。
