# 文本编辑

从文本编辑切换到节点编辑（包括定位 Clip）时，使用 Dagre 按流程从左到右排列节点，分支上下分列。节点图顶部的「一键排列」可再次排列并适应画布。排列使用节点实际尺寸，只更新并保存图中坐标；文本、Clip、连线及出口保持原样。未连接的节点也参与排列。

编辑区默认打开「文本编辑」，顶部可切换「节点编辑」。两种视图共享同一份对话数据，不保存第二套节点或连线。新建文件使用侧栏内的文件名输入框，创建后直接打开。

「编辑内容 → 预设实体」管理工作区共享的人物预设（Talker 人名、Subtitle 副标题）。预设自动保存在工作区根目录 `EntityPresets.json`，副标题允许为空；未填写人名的草稿不会出现在对话新增区。右侧「添加对话」保留默认对话，并列出已命名预设。点击人物后在当前集合末尾或所选出口新增空白 Dialogue，复制人名与副标题、样式使用 `Default_UI`。这是创建时的独立副本，修改或删除预设不会影响已有对话。

- `utils/dialogueTextPreview.ts`：从业务 Clip 与实际出口连线派生文字集合。连续 Dialogue Group 合并，附带 Camera、事件等演出 Clip 不截断集合，各句显示所有演出轨道中的 Clip 总数（不含 Dialogue 和 Select）。无 Dialogue 的演出节点、选项卡、对话 + 选项、条件节点独立显示。合流及返回目标保留边界。
- `utils/dialogueTextPreviewLayout.ts`：仅负责自上而下的布局，回接和跨层连线从外侧绕行。位置不回写原图；框高由文本视图实际测量。
- `DialogueTextPreview.vue`：纵向文字画布与右侧集合操作面板。点击集合会选中整个集合；右侧添加内容、选择出口及改接均作用于当前选择。分支并排显示，提供聚焦和散落内容定位。
- `components/DialogueTextLine.vue`：行号、角色头像、说话人、副标题（Subtitle）及其右侧的样式选择在上，自动撑高的台词输入框在下。样式复用节点编辑器的注册表，默认 `Default_UI`，保留已有自定义样式。附带 Clip 的句子持续显示数量按钮，点击可定位其节点并配置 Clip。原生输入框支持中文输入法和文本选择。
- `utils/dialogueTextEditing.ts`：只修改已有 Dialogue 的文本及样式属性，保留其他 Clip 配置。
- `utils/dialogueTextActions.ts`：新增、插入、排序、选项分支和改接操作。先在副本上完成结构变化，再一次性更新工程，避免同步保存和出口清理读到中间状态。

空白处左键拖动或中键拖动可平移，滚轮上下阅览，Shift+滚轮横移。顶部选择集合或点击出口旁的箭头可聚焦目标。散落提示统计未接入开始流程的集合、选项及条件等节点，点击循环定位；右侧连接下拉框可以将它们接回流程。

每句右上操作区提供「删除」。普通对话连同其 Group 和附带演出 Clip 删除，所有前驱出口接回该句原有后续；末句删除后前驱变为未连接。带 Select 的节点只删除 Dialogue，保留选项、演出 Clip 及选项连线。顶部「撤销删除」可在继续编辑前恢复最近删除的内容与连线；后续内容修改或离开文本视图后不再保留此单步撤销，避免覆盖新的修改。

选项和条件分支项右侧的「×」删除该项及其出口连线，下游集合保持原样；最后一项也可删除，空选项卡可从右侧重新增加选项。卡片标题栏及右侧操作面板提供整个集合／节点的删除（开始节点除外）。普通对话集合删除所有包含的 Group 与 Clip，并接回单一后续；选项卡、条件分支、演出和结束节点删除自身及相关连线，不选择分支也不级联删除下游。新产生的未接入内容沿用散落文本提示。上述删除均支持立即撤销。

Ctrl+Enter 插入下一句，Enter 在台词内换行。台词把手可在集合内拖动，↑ / ↓ 按钮或 Alt+↑ / ↓ 也可排序。排序更新真实连线顺序，附带 Clip 随原句移动，每句保留业务 ID 和配置。相邻相同角色、副标题及样式的标签只显示一次，聚焦该句时仍可修改。对话 + 选项节点单独显示；其句内插入操作在该节点之前添加对话。

右侧「默认对话」在所选出口后创建默认 Dialogue Group；在纯对话集合末尾添加时会合并回当前集合。「添加选项卡」创建独立的 Select-only Group（两个选项），不转换或修改前一句 Dialogue，也不预先生成分支台词。「添加条件分支」同样创建独立节点。若出口已有去向，则把旧去向保留到新节点的第一个出口。选择选项出口后再添加默认对话，可以建立对应的后续集合。「增加一个选项」仅增加选项，不自动生成对话。条件表达式和详细 Clip 配置仍通过节点图 / Timeline 编辑。

编辑自动保存，Ctrl+S 下载继续走原有逻辑。节点图布局坐标保持独立；新增对话、选项卡或条件分支会同步创建对应的可见节点。

每个选项显示图标缩略图与可编辑的 ID，新选项默认 `100160`，已有 ID 保留。点击缩略图打开与客户端动画编辑器共用的图片资源库，支持分类、搜索 ID、选择图片及清空（ID `0`）。两个编辑器共用 `Public/CustomUIImage/data.json`，其中 img 和 border 路径相对于 data.json 所在目录解析；对话选项不加载 border。打开图库时重新获取索引，也可点击“刷新”获取原址更新的数据。文本编辑和节点图的 Select Clip 参数面板共用此控件与选项数据。
