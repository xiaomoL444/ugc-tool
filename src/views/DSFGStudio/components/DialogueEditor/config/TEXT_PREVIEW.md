# 文本编辑

Clip 参数页点击页外即关闭，保留当前 Timeline 与 Clip 选择；点击其他 Clip 可直接切换参数页。从参数页内开始拖选文字或拖动，即使在页外松开也保持参数页打开。参数页内的下拉菜单、右键菜单及图标选择窗口属于同一操作范围，不触发页外关闭。节点图空白处第一次点击只关闭参数页，参数页已关闭后沿用原有 Timeline 关闭行为。

Group Timeline 支持右键操作：右键轨道可在点击的时间位置添加／粘贴 Clip，右键 Clip 可复制／删除。复制保留参数和输入草稿，可在不同 Group 的同类型轨道间粘贴；副本重新生成 Clip、组件和选项 ID，不复制节点出口连线。对话、选项卡和强制跳过轨道各限一个 Clip，已有 Clip 时禁用添加／粘贴。轨道标签右键使用默认时间（强制跳过为 1 秒，其余为 0 秒）；添加、粘贴和删除均接入统一撤销历史。

节点图支持 Ctrl/Cmd+C、Ctrl/Cmd+V 复制粘贴选中的普通事件和条件分支节点，多选时保留选中节点之间的连线。每次粘贴重新生成节点、Clip、轨道、组件、选项及条件出口 ID，并更新副本内部的连线；GUID、实体查询、参数、台词及备注保留原值。副本逐次向右下错开并选中，一次粘贴对应一步撤销。复制内容使用系统剪贴板，可粘贴到其他对话文件；在输入框中保留原生文字复制粘贴。

对话工具栏提供「撤销」「重做」，文本、节点图和 Timeline 共用最近 100 步编辑历史。新增／删除节点、连线／重连、排列、文字与 Clip 参数修改都可恢复；一次拖动或一次输入框编辑作为一步。画布选中状态和尺寸测量不计入历史。画布支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Y，输入框保留浏览器原生文字撤销，工具栏可撤销整个编辑操作。恢复结果进入原自动保存队列；成功打开、导入或删除文件时重置历史，防止跨文件恢复。

卡片底部的出口圆点／编号可点击或通过键盘选择，选择后同步右侧「添加到哪个出口」与「后续连接」，并高亮对应圆点。已连接与未连接出口均可选；点击仅切换操作目标，不跳转到下游、不改动连线。选项行的「从此出口添加」使用同一选择逻辑，新增内容或设置后续连接均作用于选中的出口。

集合／节点定位下拉放在右侧操作栏顶部，与当前集合的操作集中在一起。画布顶部仅保留紧凑的统计、新建和缩放工具，按钮与操作提示各自保持单行；窄窗口可横向滚动，避免下拉换行撑高顶部、挤占画布。

编辑器各模块的下拉统一为白底圆角菜单、紫色高亮和勾选状态。原生 option 声明通过 `StudioSelectField` 渲染，保留数值／字符串／未定义值、禁用选项及 change 处理；可搜索的公共事件、镜头和任务树保留搜索及分组交互，共用 `studioSelectTheme.ts` 和 `studioSelect.css`。所有 Clip 菜单保留 `data-clip-editor` 点击边界，避免选项点击关闭参数面板。

右侧「添加到哪个出口」和「后续连接」与对话样式共用 `StudioSelect` 圆角菜单：紫色高亮和勾选标识当前项，支持键盘操作、屏幕边缘向上展开及长列表滚动。出口与连接只显示业务名称，不展示内部 ID；选择「未连接」仍断开当前出口，选择出口仅切换后续操作的目标。

对话样式预设的 `showTitle` 控制标题（现有说话人 / Talker）与 Subtitle：默认样式和底部对话文本开启，其余系统样式及新建自定义样式关闭。文本编辑在关闭时隐藏头像、说话人和副标题输入，仍可选择样式；导出同时将 talker、subtitle 写为空字符串，不删除工程中的已填原文。切回开启的样式后恢复显示。自定义样式可在预设设置中切换，读取工作区预设后才允许导出。

台词的对话样式使用与工作区一致的白色圆角菜单，分别显示样式名称与 ID，以紫色和勾选标记当前项。菜单独立于缩放画布定位，靠近屏幕底部时向上展开；支持方向键、Home/End、回车或空格选择，Esc、Tab、点击外部及画布滚动关闭。已有自定义样式 ID 仍保留。

点击台词说话人左侧的头像／代号可打开预设实体选择窗口，支持按实体代号或实际人名搜索。选中后只将预设的 Talker 填入当前句的说话人，保留副标题、台词和其他 Clip 设置；原有输入框仍可手动编辑。弹窗标记当前说话人，支持 Esc 或点击遮罩取消，预设加载失败时可重试。

选项卡的 Clip 设置提供与对话一致的整数入参列表，可添加、删除和上下移动，最多 100 项。编辑值以字符串草稿保存，导出时校验 Int32 并按顺序写入 `DialogueSelectData.params`；运行时导入保留入参，旧工程缺失此字段时默认空列表。

从文本编辑切换到节点编辑（包括定位 Clip）时，使用 Dagre 按流程从左到右排列节点，分支上下分列。普通节点按实际出口顺序、条件分支按输出列表顺序约束目标节点从上到下排列，避免选项分支倒序造成交叉；不依赖连线创建顺序或出口 ID 的字母顺序。重复目标去重，共享目标要求相反顺序时保留先建立的顺序约束，避免布局约束成环。节点图顶部的「一键排列」可再次排列并适应画布。排列使用节点实际尺寸，只更新并保存图中坐标；文本、Clip、连线及出口保持原样。未连接的节点也参与排列。

编辑区默认打开「文本编辑」，顶部可切换「节点编辑」。两种视图共享同一份对话数据，不保存第二套节点或连线。新建文件使用侧栏内的文件名输入框，创建后直接打开。

「编辑内容 → 预设实体」管理工作区共享的人物预设（Talker 人名、Subtitle 副标题）。预设自动保存在工作区根目录 `EntityPresets.json`，副标题允许为空；未填写人名的草稿不会出现在对话新增区。右侧「添加对话」保留默认对话，并列出已命名预设。点击人物后在当前集合末尾或所选出口新增空白 Dialogue，复制人名与副标题、样式使用 `NOLOC_Default`。这是创建时的独立副本，修改或删除预设不会影响已有对话。

- `utils/dialogueTextPreview.ts`：从业务 Clip 与实际出口连线派生文字集合。连续 Dialogue Group 合并，附带 Camera、事件等演出 Clip 不截断集合，各句显示所有演出轨道中的 Clip 总数（不含 Dialogue 和 Select）。无 Dialogue 的演出节点、选项卡、对话 + 选项、条件节点独立显示。合流及返回目标保留边界。
- `utils/dialogueTextPreviewLayout.ts`：仅负责自上而下的布局，回接和跨层连线从外侧绕行。位置不回写原图；框高由文本视图实际测量。
- `DialogueTextPreview.vue`：纵向文字画布与右侧集合操作面板。点击集合会选中整个集合；右侧添加内容、选择出口及改接均作用于当前选择。分支并排显示，提供聚焦和散落内容定位。
- `components/DialogueTextLine.vue`：行号、角色头像、说话人、副标题（Subtitle）及其右侧的样式选择在上，自动撑高的台词输入框在下。样式复用节点编辑器的注册表，默认 `NOLOC_Default`，保留已有自定义样式。附带 Clip 的句子持续显示数量按钮，点击可定位其节点并配置 Clip。原生输入框支持中文输入法和文本选择。
- `utils/dialogueTextEditing.ts`：只修改已有 Dialogue 的文本及样式属性，保留其他 Clip 配置。
- `utils/dialogueTextActions.ts`：新增、插入、排序、选项分支和改接操作。先在副本上完成结构变化，再一次性更新工程，避免同步保存和出口清理读到中间状态。

空白处左键拖动或中键拖动可平移，滚轮上下阅览，Shift+滚轮横移。顶部选择集合或点击出口旁的箭头可聚焦目标。散落提示统计未接入开始流程的集合、选项及条件等节点，点击循环定位；右侧连接下拉框可以将它们接回流程。

画布左上角的「对话总览」展示完整流程、分支和返回连线，蓝框对应当前可见区域，随滚动、缩放及卡片高度变化更新。拖动蓝框平移视野，点击框外定位，聚焦缩略图后可用方向键移动；点击标题可收起。总览只操作画布滚动，不修改对话数据或节点坐标。

每句右上操作区提供「删除」。普通对话连同其 Group 和附带演出 Clip 删除，所有前驱出口接回该句原有后续；末句删除后前驱变为未连接。带 Select 的节点只删除 Dialogue，保留选项、演出 Clip 及选项连线。删除纳入工具栏的统一历史，继续编辑或切换文本／节点视图后仍可逐步撤销并重做；单独使用文本预览组件时保留原有「撤销删除」兼容入口。

选项和条件分支项右侧的「×」删除该项及其出口连线，下游集合保持原样；最后一项也可删除，空选项卡可从右侧重新增加选项。卡片标题栏及右侧操作面板提供整个集合／节点的删除（开始节点除外）。普通对话集合删除所有包含的 Group 与 Clip，并接回单一后续；选项卡、条件分支、演出和结束节点删除自身及相关连线，不选择分支也不级联删除下游。新产生的未接入内容沿用散落文本提示。上述删除均支持立即撤销。

Ctrl+Enter 插入下一句，Enter 在台词内换行。台词左侧仅显示序号和拖拽把手，可在集合内拖动排序，也支持 Alt+↑ / ↓ 键盘排序。排序更新真实连线顺序，附带 Clip 随原句移动，每句保留业务 ID 和配置。相邻相同角色、副标题及样式的标签只显示一次，聚焦该句时仍可修改。对话 + 选项节点单独显示；其句内插入操作在该节点之前添加对话。

右侧「默认对话」在所选出口后创建默认 Dialogue Group；在纯对话集合末尾添加时会合并回当前集合。「添加选项卡」创建独立的 Select-only Group（两个选项），不转换或修改前一句 Dialogue，也不预先生成分支台词。「添加条件分支」同样创建独立节点。若出口已有去向，则把旧去向保留到新节点的第一个出口。选择选项出口后再添加默认对话，可以建立对应的后续集合。「增加一个选项」仅增加选项，不自动生成对话。条件出口可直接点击“编辑条件”，使用可视化比较行、且／或及嵌套括号组，或保留表达式原文编辑。只有保存才提交项目，取消不改变数据；无法转换的旧表达式不会自动覆盖。详细 Clip 配置仍通过节点图 / Timeline 编辑。

编辑自动保存到当前工作区，不提供编辑器 JSON 下载快捷键。节点图布局坐标保持独立；新增对话、选项卡或条件分支会同步创建对应的可见节点。

每个选项显示图标缩略图与可编辑的 ID，新选项默认 `100160`，已有 ID 保留。点击缩略图打开与客户端动画编辑器共用的图片资源库，支持分类、搜索 ID、选择图片及清空（ID `0`）。两个编辑器共用 `Public/CustomUIImage/data.json`，其中 img 和 border 路径相对于 data.json 所在目录解析；对话选项不加载 border。打开图库时重新获取索引，也可点击“刷新”获取原址更新的数据。文本编辑和节点图的 Select Clip 参数面板共用此控件与选项数据。
