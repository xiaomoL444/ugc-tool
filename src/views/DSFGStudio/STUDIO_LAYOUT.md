# DSFG Studio 布局

页面使用 A 系列概念图的单侧导航结构。只调整 DSFG Studio，App.vue 的顶部栏由应用自身管理。

- 左栏上方为工作区选择、新建／删除与对话、任务、镜头、场景、预设五个功能入口。对话入口下有演出对话与边走边说两个模式。
- 左栏下方显示当前编辑器的文件列表、任务树、场景层级或预设分类。右侧为完整编辑区域。
- 预设分类下方增加「其他」分组，首项「多语言文本管理」展示客户端文本映射 ID、翻译标记及 15 种语言。支持搜索和语言筛选，默认显示完整表格，横向滚动仅限表格内；查看不写入工作区或编辑历史。两种语言文件直接从正式 OSS `https://oss.xiaomol444.xyz/ugc-tool-data/DSFGStudio/SaveI18nFile/AllLanguage.csv` 和同目录 `ChineseLanguage.csv` 下载，开发环境也使用该地址。
- 新建工作区、演出对话文件及边走边说文件使用 `StudioCreateDialog.vue` 的紧凑悬浮框，不占用侧栏空间。打开后聚焦名称输入框，支持回车创建、Esc／点击背景关闭；创建期间禁用提交和关闭。
- Group Timeline 的「＋ 添加事件」展开「添加公共事件／添加自定义事件」菜单，事件轨道不设数量上限。旧文件中的 `timeline.maxLines` 在读取时忽略，已有轨道和 Clip 完整保留。
- 镜头入口支持每个工作区建立多份独立镜头编辑文件，保存于 `CameraEditor/*.json`，一份文件对应一个镜头。复用相机位置／视点位置表单，单独编辑时长；切换文件、功能或工作区时先保存，删除进入回收站。新建使用悬浮小框，Ctrl+S 保存到工作区，刷新后可从列表重新打开。导出为千星 CameraClip 根结构，与演出对话共享工作区的镜头及嵌套结构体 ID。
- 编辑器通过 `StudioSidebarContent.vue` 将原有导航呈现在统一左栏，仍拥有数据、事件和选中状态。切换工作区或功能仍先执行 `prepareToLeave`，并以原有组件 key 隔离状态。
- 被移动的导航脱离了原编辑器的 DOM 父级，必须显式传入 `inert`／禁用状态。任务树通过 `sidebarDisabled` 接收读写状态。离开编辑器时导航会一起卸载。
- `studioShell.css` 的选择器必须限定在 `#app .dsfg-studio` 内。边框标题使用正常文档流和分段边框，避免遮挡控件。表单、卡片和工具栏使用浅色表面。预设上方为淡底系统卡片，下方为自定义卡片；系统代号／显示名称固定，实际值可编辑，系统项不能新增或删除，自定义项可自由增删改。固定协议选项保持只读。公共事件参数区默认折叠，展开控件放在卡片顶部右侧，与代号和事件名同一行；展开后可编辑参数及显示条件。
- 公共事件的参数名称、类型、值来源和默认值按卡片可用宽度排列为四列、两列或一列。显示条件使用独立全宽区域，每条规则分行排列，增删按钮和参数操作始终可见，公共参数区不使用横向滚动。自定义配置记录表格仍可横向滚动。
- 预设编辑区顶部始终使用同一个“词条”按钮控制左侧词条／代号浏览面板，按钮位置在展开和收起时保持一致。展开列表透明底融入原淡紫布局，仅显示当前选中分类的词条，按系统／自定义分组，使用紧凑代号／显示名称；搜索匹配名称、代号和完整事件名等实际值。点击条目定位当前分类的对应卡片，切换分类时清空搜索。收起时整栏及其边界隐藏，编辑区恢复全宽，无竖线或悬浮把手；顶部按钮保留，收起期间保留搜索值和浏览界面状态。浏览、搜索、定位及折叠状态不写入工作区数据，不进入编辑历史；词条列表复用已挂载分类的预设状态。
- 任务编辑器现已提供任务衔接图，与属性列表共用后续任务及失败回溯数据；播放模拟等概念示意功能尚未实现。现有导出格式沿用原实现。
- 场景编辑器可切换「场景属性／场景示意图」。示意图按世界 → 一级区域 → 二级区域嵌套包围，自动按内容撑开外框；世界之间按已有连接点绘制深蓝有向连线，并标注目标点位坐标。点击选中、双击进入属性，也可用「编辑所选属性」按钮；拖动世界标题整体移动，空白和分组背景支持左键平移，右键可在图内任意位置平移，支持缩放、适应画布及整理布局。无效父级放入未关联分组，缺失目标连接单独提示。布局仅保留在当前编辑会话，切换属性视图后仍保留；不写入场景配置、不改变归属和连接点坐标。验证：`node scripts/test-dsfg-scene-graph.cjs` 与 `node scripts/test-dsfg-scene.cjs`。

验证：`node scripts/test-dsfg-studio-shell.cjs` 检查实际组件编译、样式作用域及侧栏挂载／切换／禁用／卸载；`node scripts/test-dsfg-quest-integration.cjs` 检查保存和工作区切换保护。

## 工作区结构体 ID

工作区选择器右侧「… → 设置结构体 ID」集中管理演出对话（9 项）、任务（5 项）、边走边说（2 项）和场景（5 项）。保存到工作区根目录 `StructIds.json`；各模块导出时读取同一份配置，覆盖外层及嵌套类型引用，不批量重写编辑文件。

尚无集中配置时，从当前工作区的旧文件读取自定义 ID；同一项只有一个自定义值时沿用，多个值时在统一窗口列出候选并要求选择。读取失败的旧文件仅提示，不覆盖。已有集中设置损坏时禁止用默认值覆盖，保留原文件并显示重试。

「读取 GIL」在本机解码结构体定义表（10/6），按结构体名称匹配编辑及运行时快照并去重。未匹配项保留草稿，多个同名 ID 必须选择；只有点击保存才生效。GIL 不会被上传或修改。

同一次读取还会从技能定义表（15/1，类型 6）按名称匹配当前工作区的技能动画预设，兼容 `[演出]` 和 `[演岀]` 前缀。弹窗显示现有 ID → 识别 ID；未匹配和未选择的歧义项保留现有值，不新增预设。技能变更与结构体草稿共用弹窗撤销／重做，取消不写文件；「恢复默认结构体 ID」仅重置结构体草稿。保存先写结构体，再通过预设保存队列写技能配置 ID；技能保存失败时恢复导入前的内存预设并清理失败快照，保留弹窗草稿供重试，取消后不会在后台写入导入值。预设读取损坏时保留原文件，仍可单独识别和保存结构体。

打开设置前刷新所有已挂载编辑器的保存队列。成功保存技能后刷新缓存消费者，并重置对应预设分类的编辑历史基线；其他分类历史保留。修改技能预设不回写已有 Timeline／公共事件动作中的 ID，已有动作需要重新选择动画。
