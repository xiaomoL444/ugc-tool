# 角色动画查看器

入口 `/AnimationViewer`。顶部沿用 BGM 播放器的两行布局：第一行显示搜索、匹配的动画片段总数和全部展开／收起；第二行显示分类及片段数量、版本筛选，不提供时长筛选。分类按钮直接采用 BGM 页的结构和样式，所有按钮统一使用默认紫色及其展开状态；分类细线框和标题按 ID 固定配色：1 蓝、2 绿、3 紫、4 红、5 金、6 青、7 靛，其余 ID 使用默认紫色。配色沿用音效页，不随排序、搜索或刷新变化。收起分类会移除整块栏目；片段名称仅显示在预览下方。

卡片下方的动画名称、组合技能标题和放大预览标题均可点击复制当前语言显示的名称，复用网站统一的剪贴板工具及成功／失败提示；点击名称不会打开放大预览。

## 数据接入

页面通过 `createOss("AnimationViewer")` 请求模块根目录的 `data.json`，资源名称翻译按现有约定读取 `i18n/<locale>.json`。当前不附带数据或示例素材；索引返回 404 或没有技能数据时，内容区留空，不生成默认分类、版本筛选或空状态插画。分类只读取索引中的 `category`。其他网络错误和无效配置有各自的重试状态。

索引格式为 `{ data: AnimationSkill[], category: AnimationCategory[] }`，完整类型和校验位于 `animationData.ts`。

- 分类记录：`id`、`nameI18nKey`。
- 技能记录：`type`、`category`、`nameI18nKey`、`parts`，可选 `order`、`giVersion`。技能不需要 ID，片段通过嵌套关系归属到技能。
- `giVersion` 为该技能所属游戏版本的字符串，例如 `"6.0"`；省略或留空时不归入具体版本，但仍在“全部版本”中显示。版本筛选和名称搜索共同作用于整组技能，前摇、持续、后摇始终一起保留。
- 技能级 `type` 仅支持 `single`（单段技能，一个片段）和 `combo`（组合技能，按顺序组织具名片段）；分类由 `category` 单独指定。
- 片段记录：必填 `type`、相对模块根目录的 `path`，可选 `nameI18nKey`、`duration`。路径不自动附加 `webm/` 等子目录。
- 片段级 `type` 仅支持 `single`（单段动作）和 `continuous`（持续动作），独立于技能级 `type`。单段技能也可以包含一个持续动作。
- `data[].parts[].duration` 表示该片段在技能中的实际时长，单位为秒，填写正数，可含小数。它独立于预览视频长度；未知时省略，页面不会从视频长度推算。
- 持续施法、位移、瞄准和套组中由多个片段组成的技能统一使用 `combo`。各片段按 `parts` 数组顺序显示，每段必须有自己的 `nameI18nKey`。前摇、持续、后摇通过这些名称表达，不使用 `phase`，也不根据片段类型自动猜名称。例如三段依次命名为前摇、持续、后摇，片段类型依次为 `single`、`continuous`、`single`。
- 单段技能中的片段可省略 `nameI18nKey`，此时使用技能名称；填写后优先使用片段名称。
- `nameI18nKey` 使用完整的 `animationViewer.*` 翻译键；语言文件为平铺的键值对象。

列表使用与特效页相同的 `vueuc` `VVirtualList`，将原有响应式网格按行虚拟化，只挂载视口附近的行。组合技能始终整组分行，不拆散前摇、持续和后摇；分类线框由首行、连续的中间行和末行拼接，收起后整栏移除。行高度随卡片尺寸、名称换行和手机纵向组合布局自动测量。搜索、切换版本或切换分类后回到列表顶部。全部分类均展开时按钮显示“全部收起”，否则显示“全部展开”；折叠不会改变分类数量或总数。

每段均静音、自动循环预览，无播放／暂停按钮。当前挂载行在滚动容器上下 240px 内提前加载，进入视口后播放，离开视口立即暂停。虚拟行卸载时，视频暂停并从页面移到缓存；复用特效页的媒体池，最多保留 64 个闲置播放器，回看时复用原视频、缓冲和暂停位置，超出上限才释放最早闲置的资源。页面隐藏或打开放大预览时暂停卡片，恢复后仅可见卡片继续播放。点击卡片打开原生对话框放大预览，卡片与弹窗使用独立播放器。

折叠后重新展开时，卡片在首次绘制前同步接回已有缓存，避免等待可见性回调时闪过加载提示。此步骤只取已有播放器，不创建新视频；未缓存的片段仍按可见范围加载。超过 64 个闲置播放器上限而被淘汰的片段，回看时需要重新加载。

页面继续请求原始 `path`，按视频原速播放，不改变任何视频文件、分辨率、编码、帧率或实际时长。片段的 `type: "continuous"` 会显示循环标记；此标记与已填写的实际时长同时显示，片段类型不改变预览视频循环播放的行为。

## 验证

`node scripts/test-animation-viewer-data.cjs` 检查配置契约，`node scripts/test-animation-viewer-rows.cjs` 检查分行与响应式布局，`node scripts/test-animation-media-pool.cjs` 检查缓存复用和上限。浏览器回归使用 `scripts/test-animation-viewer-browser.cjs`，测试索引、语言表和视频均由测试内存提供，不会写入正式资源目录。
