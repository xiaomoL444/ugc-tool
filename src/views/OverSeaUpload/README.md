# 关于海外上传预览页的工具



因为这里面要用到奇匠自己的鉴权码可能纯在风险，这里说明一下，鉴权码在发送给了一个我自己挂在cloudflare上的一个worker，仅用来做转发使用，均不与本人有任何接触（并且我也没有这个闲情也没有财力购置自己的伺服器存这些东西()）

视频提交保留服务端返回的媒体引用：新上传视频使用 OSS 回调中的原始路径，尚未返回 `video_id` 时提交空字符串；已有视频沿用详情接口返回的地址和 ID。文件名和 OSS 对象 key 不作为 `video_id`。相对路径仅在预览和 ZIP 导出下载时补全 CDN 地址，ZIP 导入重新上传的视频遵循同一规则。

OSS 上传按服务端返回的 `dir + name`（或 `key`）填写对象路径，并固定发送 `success_action_status=200`。只有 HTTP 200 且回调 JSON 的 `retcode=0` 才确认上传成功；空回调、非零返回码和未确认的响应不会标记为成功。

视频请求回归检查（模拟接口响应，不向线上提交）：

```sh
node scripts/test-oversea-upload-video.cjs
```
